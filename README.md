# sabore
Plataforma de gastronomia que reúne receitas brasileiras e internacionais, livro de receitas digital pessoal, comunidade culinária, chatbot com inteligência artificial e compartilhamento de receitas. Modelo freemium com publicidade e assinatura Saborê Pro por R$ 4,99/mês, com experiência sem anúncios para assinantes.
